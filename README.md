LED Blinking

A basic Arduino project created and simulated using Tinkercad.

Project Description

This project demonstrates how to control an LED using an Arduino. The LED is programmed to turn ON and OFF at regular time intervals, creating a blinking effect.

Components Used

- Arduino Uno
- LED
- Resistor
- Jumper wires

Working

The Arduino sets the LED pin as an output. In the "loop()" function, the LED is turned ON, waits for a specified time, then turns OFF and waits again. This process repeats continuously.

Files

- "LED_Blinking.ino" — Arduino source code
- "LED_Blinking.brb" — Tinkercad project file

Simulation

The project was created and tested using Tinkercad Circuits.
